# 公开文件与外部数据

RFW-W 公开代码、配置模板与明确标识的小型合成输入。模型权重、第三方源码、完整资产库、索引、prepared、outputs 和历史运行证据存放在外部数据根。

本机真实路径通过环境变量或 gitignored 配置传入；源码、公开文档和可分发测试数据使用中性占位符。凭证与非公开端点不入库，检查凭证时只报告 set/unset。

对外模型请求只包含授权的任务语义或图像；仓库文件、目录、路径和日志不得发送给模型。各管线的模型开关和任务授权共同决定是否执行请求。

发布前运行 `python scripts/scan_sensitive.py`。扫描覆盖根文档及 `assets`、`configs`、`docs`、`examples`、`scripts`、`src`、`tests`，包括源码树内的 vendor 文件。组织内部关键词写入 Git 忽略的 `.sanitize-keywords.local`，每行一个且不得提交；清单缺失或为空时返回 `blocked`（退出码 2），不再跳过检查。`-v` 预览也会对内部关键词打码。

扫描通过不替代人工核对数据许可、外部依赖获取方式与生成/仿真验收范围。模型权重、数据集和资产库的许可边界见 [THIRD_PARTY.md](../THIRD_PARTY.md)。提交、推送及发布按用户明确授权执行。
