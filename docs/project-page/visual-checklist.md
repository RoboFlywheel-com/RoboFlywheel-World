# RFW-W Project Page 可视化清单

用途：本地审片，不是发布授权。参考 [RFW-Soft 项目](https://github.com/roboflywheel-com/RoboFlywheel-Soft) 的「实景首屏 → 浏览样例 → 检视物理表示 → 看任务证据」顺序；不沿用 Soft 的规模数字、验证结论、作者或论文链接。

| 优先级 | 展项 | 已找到的材料 | 页面验收 / 缺口 |
| --- | --- | --- | --- |
| P0 | 首屏与项目演示 | 完整项目演示及片中海报 | 背景和弹窗共用完整原片，任务录像单独选择 |
| P0 | 刚体样例 | v1.3 映射表、外观网格、纹理、MJCF 分解凸包；另有 40 段历史转台 | 按映射选样并从当前包重绘；不以旧转台替代当前发布几何，不把分类目录数当作库规模 |
| P0 | 外观与碰撞 | 同一 MJCF 包中两套网格 | 固定相机、姿态和比例；切换显示仍能定位同一部件。凸包着色仅用于区分几何，不代表材质 |

| P0 | 方法与论文 | 稿件中的刚体构建图、任务场景图、署名及结果 | 论文样本规模、场景满足率、策略成功率与本地展示件数分别标明；不公开稿件仓库 |
| P1 | 一条可追溯的资产到任务链 | 两条管线均有样例，尚未在本页建立同版本关联 | 补同一个 release leaf 的绑定、场景布局、开场/结束帧、判定规则与对应执行记录 |
| P1 | 场景空间关系 | 室内斜视录像可用 | 补同一场景的俯视图，标出任务目标、支撑面与可达区；不要由透视图猜尺寸 |

| P0 | 自由视角 3D | 每件资产都有匿名外观和碰撞 GLB | 在本地预览自由旋转、缩放、切换表示；浏览器收到的是可提取的展示几何，公开分发仍需许可 |
| 发布门槛 | 对外资源 | 代码许可独立于模型、影像与数据许可 | 确认样例/场景/音轨分发权、最终作者、论文与数据入口；未确认的不展示下载按钮或全库统计 |

预览包使用匿名展示几何、海报和精选录像。源模型、映射表、历史完整录像库和运行日志不进入站点。

本轮已接入：18 类、82 件刚体资产，共 164 个可交互模型；另有 4 段场景录像、1 部完整项目演示和 2 张论文管线图。园艺阳台标记为局部操作。此处数量是展项数，不是数据集统计。

资产审查：累计 368 件候选，236 件未通过几何或导出检查，另有 50 件在实图复核后未入选。每件入选资产的外观及碰撞 GLB 各回读并检查 6 个视角，对比启用和禁用背面剔除时的深度，检查空白和画面裁切。该检查不保证每个角度都无缺陷，也不验证物理参数或任务成功。

配色选样：从新增的 150 件候选中选入 34 件，按真实外观海报而非材质描述确认颜色，不修改纹理、不将碰撞凸包的配色计入。首批 18 件交错展示不同轮廓、实色和纹样，包括西瓜摆件、紫色头盔、红色烤模、青绿色奶油壶、黄色收纳盒和蓝花餐盘。
