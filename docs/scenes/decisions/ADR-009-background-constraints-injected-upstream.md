# ADR-009：外围生成接受任务保留区，并在构建内拒绝违规候选

- 状态：accepted（2026-09-22，含后续机制修正）。
- 前序：[ADR-007](ADR-007-generated-background-around-frozen-core.md)、[ADR-002](ADR-002-room-shell-from-infinigen.md)。

## Context

任务核心由检索与确定性摆放冻结。可选外围生成若不知道保护区，就会占据机器人工作区、
走道或门扇扫掠。仅检查最终图片无法证明生成器遵守空间约束。

## Decision

1. 正式构建入口及 patch 位于 `rfw_w.scenes.workers.blender`，入口摘要与上游 pin 留证据。
2. 保留区进入约束图，包含 accessibility/distance 代价与有界约束；无解明确失败。
3. 保护区从地面到任务台面，走道到1.8米，另含门扇扫掠；XY侵入面积必须为零。
4. 生成只补调用者明确声明的品类空缺。任务核心及检索覆盖的外围不获得第二个 owner。
5. 候选池在构建内拒绝侵入、非空缺或超预算对象，逐对象记录原因。每stage上限24件。
6. 默认检索，生成显式 opt-in。策略、空缺、保留区、拒绝账本进入构建和交付记录。
7. 独立审计核对池子与几何尺子，共用 `geometry.reservations` 的规则。
8. 缺失记录、账本不完整、保留区未满足分别给具名失败。未采样空缺与被拒候选分开报告。
9. 可选的后续资产工厂路径需要离线冻结与复验，不能暗中代替当前构建流程。

## Mechanism limits

Pinned求解器的通用collision开关只服务已禁用的floating stage，不能据其配置声称
家具碰撞已检查。代价项的强度会改变整阶段对象数量；历史权重扫描没有找到同时保护
保留区与保持原密度的连续档位。约束注入不能替代候选池，密度变化必须留证据。
某些无解来自上游lighting组，不能归因于本包约束。

## Consequences

生成可能失败或没有提出某个空缺；有界结束并报告原因，不重试挑好看的结果。
保留区对象是不可见辅助几何，不能作为家具导出。材质生成不授予可操作认证。
装配证据按 generation hash/attempt 保存，最终交付显式读取当前room plan的注入记录，
独立验证重读文件、路径和摘要。旧运行矩阵属于历史证据，当前checkout必须重新执行。
